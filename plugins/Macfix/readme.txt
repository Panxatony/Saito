The MacFix theme.

Built on Nova: this plugin carries only what makes the forum *macfix* — the
wine-red identity, the grey page its white content sits on, and the Mac system
type stack the forum has always used. Everything structural comes from Nova, so
a change there reaches this theme without being copied into it.

Compiled with `yarn css:theme` from webroot/css/src/{theme,night}.scss, together
with the other themes — the built stylesheets are a build product and are not
kept in git.

Shipped but not switched on: an installation offers this theme by naming it
under `Saito.themes.available` in its own config/saito_config.php.
