## Smilies einrichten ##

Die Smiley-Dateien liegen unter `webroot/img/smilies/`.

### Die Felder ###

#### Reihenfolge

- Aufsteigend sortiert bestimmt sie, in welcher Folge die Smilies im Forum
  angeboten werden.

#### Symbol

- Dateiname des *Symbols*, das den Smiley in der Auswahl vertritt.

#### Bild

- optional
- Dateiname des *tatsächlich eingesetzten Bildes*.
- Bleibt das Feld leer, wird das Symbol verwendet.

#### Titel

- optional
- Beschreibt den Smiley; das Forum zeigt den Text als Kurzhinweis an.
