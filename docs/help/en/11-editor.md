## Writing postings

The editor opens when you start a new thread or answer a posting. A row of
buttons sits above the text box; you write below it. None of it is required — a
posting of plain text is a complete posting.

### Subject

On an answer, the original posting's subject stands faintly in the field. That
is a suggestion, not content: type nothing and it is taken over with *Re:* in
front. As soon as you start typing, it disappears.

How long a subject may be is up to the operator. The field is exactly as wide as
the text it accepts, so it never looks as though more would fit.

### Marking up text

Select the text and press the button — the markup wraps around the selection.
With nothing selected, the pair is inserted at the cursor and you carry on
writing between the two halves.

* **Bold** and *italic* for emphasis
* ~~Struck through~~ for what you take back
* Quote for longer passages taken from another posting
* Code for commands, output and program text that must be reproduced verbatim
* List for enumerations. Each further item starts with `[*]`
* Spoiler for content not everyone should see at once — it appears only when
  somebody clicks the covered area

### Links and embedded content

One button covers both. What you get does not depend on which button you pressed
but on the address you point at: a video becomes playable, an image address
becomes an image, anything else becomes a link.

If text was selected when you pressed it, that text is offered as the link text
straight away. When the linked page provides a preview — title, description,
image — you can choose between a plain link and a preview card. The preview
shows what it will become before you insert it.

For **YouTube and PeerTube** the address from the address bar is enough —
including the short `/w/…` form PeerTube shows. The editor turns it into the
player's own address by itself. Whether the video then appears still depends on
the forum allowing that domain; if it is not on the list, a note appears in
place of the video.

### Files

The *Uploads* button opens your archive and takes new files at the same time.
*Images and files* covers it in full.

### Smilies

The button with the face opens a picker. A click puts the smiley at the cursor;
the picker stays open so you can take several in a row.

### Preview

*Preview* shows the posting as it will appear in the thread — images, links and
preview cards included. What you wrote is left untouched.

### Shorthands

These work as you type, without any button:

* `#123` links to the posting numbered 123
* `@name` links to a member's profile
* A quote character at the start of a line, followed by a space, turns that line
  into a quote from the parent posting
* An address in the text becomes a clickable link by itself

### Drafts

What you write is saved a few seconds after you stop typing. Open the same reply
again — after closing the tab, after a crash, tomorrow — and it is waiting for
you, with a note saying where the text came from and a button to throw it away.

One draft per posting you are answering. It goes when you post, and after thirty
days untouched. Saving happens quietly: you did not ask for it, and the text is in
front of you anyway.

If a form comes back with an error, what you just typed always wins over the
draft.

### Every markup tag

The button row covers the usual cases. If you need more, the
[BBCode reference](webroot:help/BbcodeParser.1) lists every markup the forum
understands, each with the spelling to type.
